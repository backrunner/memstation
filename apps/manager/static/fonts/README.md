# IBM Plex Sans

Self-hosted Latin variable font, weights 400–700, SIL Open Font License 1.1.
Downloaded 2026-09-09 from Google Fonts' versioned v23 distribution:

https://fonts.gstatic.com/s/ibmplexsans/v23/zYXzKVElMYYaJe8bpLHnCwDKr932-G7dytD-Dmu1syxeKYbSB4Zh.woff2

License: https://github.com/google/fonts/blob/main/ofl/ibmplexsans/OFL.txt

Non-Latin scripts use the system sans-serif fallback. The manager does not make
runtime requests to an external font service. No package versions were changed.
