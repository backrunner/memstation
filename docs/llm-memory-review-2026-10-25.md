# LLM 记忆实现复核（2026-10-25）

本次审查覆盖未提交的 UTF-8 修复、LLM-only 生成、Worker／重建／预览、模型出站协议、数据库迁移及来源元数据、Manager 消费路径。发现的问题先由回归用例复现，再修复；当前范围内没有遗留阻塞提交的问题。

## 修复结果

| 问题 | 修复与回归 |
| --- | --- |
| 同一来源的并发任务可以覆盖摘要或分析检查点，产生不同记忆 ID | 摘要在数据库身份锁内识别同来源检查点；分析与 Key 检查点原子保留首个已验证结果。调用方读取实际持久化版本。内存与 PostgreSQL 回归、重叠模型调用用例通过。 |
| 内存检查点保留了调用方 map／slice，反序列化复用旧对象导致竞态 | 保存独立 JSON 快照，读取到新的零值对象；并发用例曾触发 race 和 concurrent map panic，修复后专项重复 10 次及相关包完整 race 通过。 |
| 重放旧会话可能把已被替代的事实重新合并到 Key Memory | 分析候选和 Key 合并跳过已替代事实，Key 检查点身份随有效事实集合改变。 |
| 旧事实数量增长后每次请求都超过 128 KiB，重试无法恢复 | 旧事实候选按完整记录限制为 32 KiB，告知模型候选是否受限；只允许引用本次实际提供的事实 ID，不截断原始对话来让旧事实占用预算。 |
| 不同分块复用条目键，导致合法分析失败或关系指向其他分块 | 关系键在各分块内解析；同块歧义拒绝，策略排除的通用条目不会造成悬空关系写入。 |
| 显式空自动写入白名单被 Viper 默认值覆盖 | 空环境变量明确关闭自动合并，增加配置回归。 |
| Key 上下文超过最近 100 条窗口后被误认为不存在 | Worker 与预览按允许键逐项读取，不依赖任意列表窗口。 |
| LLM 重放会覆盖人工修正的事实及普通记忆正文 | 在数据库身份锁内拒绝覆盖已有人工作业版本的节点，内存仓库标记对应修改；摘要、事实、画像、任务的内存／真实 PostgreSQL 回归先失败后通过。 |
| 新增事实元数据在历史快照中被嵌套，来源字段无法读取 | 更新快照触发器并修正旧快照元数据形状，保留历史内容及时间；真实 PostgreSQL 用例先复现再通过。 |
| Linux WebKit 的页面布局回归超过整项 45 秒 | 保留五档视口和全部页面断言，每档视口独立测试并记录每个路由 step；不提高全局超时或增加自动重试。 |
| Agent 重新启用按钮与退出中的确认框按钮重名 | 等待禁用确认框退出，再定位主内容中的启用按钮。 |
| 重建检查点读取没有显式 generation | 内部检查点与已存摘要读取携带目标 generation，保持隔离重建的读取边界。 |

人工修正后的原代次重放会报告冲突，保留现有正文和向量；需要重新生成时使用隔离 generation 检查并显式激活，不自动撤销人工修改。

原有 JSON schema、精确来源引用、作用域、事实替代校验、条件写入和失败重试继续保留；没有恢复任何语义规则兜底。历史数据不自动清空或重建，Personal 之外的 Workspace 类型仍不开放。

## 本地验证

- 完整 `go test ./...` 使用独立 PostgreSQL 数据库；相关服务、Worker、SQL 和 gRPC 包使用真实 PostgreSQL 再跑 `-race`。
- Go format、lint；四种模型出站接口的 Token／JSON 契约；生成代码一致性。
- Manager lint／类型检查、31 项单测（含独立 Redis DB 的真实会话共享用例）、production build；完整 Chromium／WebKit E2E 初次 100 项通过；视口分项后完整回归 108 项通过。
- 四项新迁移 Atlas lint、dry-run，全部 21 项迁移在空 PostgreSQL 库实际重放。
- Worker 恢复 smoke 与 256 会话演练、backup/restore dry-run。
- Server 覆盖率 73.4%，Manager 覆盖率 44.10%，均满足现有阈值。
- Repo-native retrieval/ranking smoke 导出诊断 artifact；使用确定性向量，只验证检索和评测链路，不代表真实模型效果，也未将 benchmark 设为门禁。
- 安装复核后的本机二进制并恢复 serve／worker／scheduler／Manager；Ollama、PostgreSQL、Redis 保持可用。真实用户样例的检查点重放、原文来源和跨会话召回通过，Manager 实际数据桌面／390px 浏览通过。

本地报告位于被忽略的 `.artifacts/review-20261025/`；真实模型报告与截图位于 `.artifacts/ollama-local/`。凭据和私有运行配置不提交。
