# Personal Workspace 累积修改复核

日期：2026-10-24。复核基线 `f336c65`，覆盖提交前 318 个累积修改文件及其关联调用；生成文件通过完整重生成比对。当前仅开放确定性 Personal 工作区，群／项目、共享私有分区、Subject／SourceEvent／Run 等仍按完整计划后续实施。

## 范围与发现

复核覆盖身份／Agent／凭据、HTTP／gRPC／工具授权、会话持久化／结束／outbox、Worker 与重建、记忆／图／历史／向量／缓存／文件作用域、版本化迁移、Manager Target 会话／代理／导航／分页／编辑和共享控件，以及部署脚本与文档。

修复四处可复现问题：

1. Gateway 在附加 Agent／credential／workspace 信息时修改调用方原始 metadata，复用请求会让前一个请求的来源变成后一个 Agent。现在读取默认配置时先复制顶层 metadata，运行期装饰互不污染；回归覆盖原始对象与先前结果不变。
2. Gateway 服务层读取用户配置发生在可信 Owner 归一化之前。现在从 AccessContext 确定身份后再读取配置，不能用传入的另一个 UserID 选中其模型默认值；回归覆盖该边界。
3. Manager 的 IPv6 公网地址判断依赖字面正则，压缩和补零写法会绕过已有特殊网段排除。改为数值前缀判断，覆盖 `2001::1`、补零、标识符范围和正常公共 IPv6 地址；既有显式目标登记仍为网络访问边界。
4. 关联目标为 Key Memory 时，工作区详情会构造普通文档路径并携带 generation，无法打开编辑页。统一 URL helper 将其映射到范围内 `/keys/:id`，不携带 generation；增加单测与 Chromium／WebKit 跳转回归。

同时更新真实服务浏览脚本中已过期的筛选控件标签断言。移动端浏览回归改为通过实际栏目链接切换并确认目标内容，避免测试中连续全页导航互相中断。以上产品回归均先确认旧实现失败，再修复验证。未发现剩余已知阻塞问题；这不等同于对所有运行环境承诺零缺陷。
