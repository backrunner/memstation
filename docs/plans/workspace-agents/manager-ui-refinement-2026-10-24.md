# 工作区选择与 Manager UI 整理

日期：2026-10-24。承接分页与导航迁移；工作区能力仍仅开放 Personal。

## 已实现

- 将工作区按钮、字符箭头和居中 Dialog 改为 Bits UI Popover。复用共享 Select 的触发器尺寸、Lucide 箭头、边框和焦点样式，弹出内容贴近触发器。上下文栏显示 Owner，避免多个空间同名 Personal 时混淆归属。
- 打开即聚焦服务器搜索框，Enter 搜索；当前项显示勾选，重复选择只关闭面板，保留详情／generation。其他空间回到对应栏目列表、保留适用筛选并清除旧记录选择；继续保留草稿离开确认。
- Escape／关闭／外部点击关闭面板，焦点恢复触发器。短屏可滚动，长名称换行；加载、空结果、错误重试及搜索分页各有明确反馈，关闭后的旧请求不覆盖新结果。
- 新增共享 MetadataRow（19 个文件、40 处调用），列表、详情、审计、任务、健康、统计、Agent 凭据、聊天调试和历史检索使用独立文本项及留白；说明和确认文案使用自然语句。清除 Manager 源码所有圆点拼接文本，不改用户保存的正文。
- 审计页仅在请求结束且无错误时展示空结果，避免“加载中”与“没有结果”同时出现。
- Key Memory 筛选与新建操作使用明确布局；窄屏输入占满一行，提交与新建按钮对齐。保留既有共享输入、Select、Button、Dialog、CollapsibleSection；不增加依赖、装饰状态灯、渐变或卡片层级。
